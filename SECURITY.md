# Security policy

## Supported versions

Security fixes are applied to the current `main` branch and, when a release is authorized, to the latest npm version. Older npm versions may not receive fixes.

## Reporting a vulnerability

Use a [private GitHub security advisory](https://github.com/yakult-green-tea/qq-music-api/security/advisories/new) for vulnerabilities, credential exposure, or authentication/session handling issues. Do not open a public issue containing sensitive details.

Never include real QQ cookies, musickey values, QR keys, opaque session values, auth-state files, `.env` contents, or complete authenticated URLs. Use synthetic values and the smallest reproducible description possible.

This is an unofficial, community-maintained project. Security reporting guidance does not imply affiliation with or authorization from Tencent or QQ Music.
